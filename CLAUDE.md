# Torsel

The code is the spec. Two rules gate every change:

1. **Three domains.** A feature enters the platform only when it serves at least three unrelated uses (workouts, body weight, expenses, habits, collections…). Anything narrower is a view's config, a formula, or something the assistant does from a prompt. A rest timer, a warmup ramp or a plate calculator is that narrower kind.
2. **Kilorep is the acceptance test.** v0 is done when four consecutive gym sessions and the daily weigh-in are logged in Torsel instead of kilorep, starting from kilorep's CSV export.
